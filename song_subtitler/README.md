# יוצר סרטוני כתוביות שירים - מדריך שימוש

## תיאור

כלי זה יוצר סרטוני כתוביות עבור שירים באופן אוטומטי. הוא משלב קובץ אודיו (MP3), תמונת רקע, כותרות (שם שיר ואמן), וכתוביות מסונכרנות בשפת המקור (אנגלית/יידיש) ובתרגום לעברית. הכתוביות נוצרות באמצעות Google Gemini API.

## דרישות

*   **Python 3.10+**
*   **Pip** (מנהל החבילות של Python)
*   **ImageMagick:** **חובה להתקין ולהוסיף ל-PATH של המערכת!** נדרש על ידי `moviepy` לעיבוד טקסט. [קישור להורדה](https://imagemagick.org/script/download.php).
*   **מפתח API של Google Gemini:** נדרש ליצירת כתוביות. [ניתן להשיג מפתח כאן](https://aistudio.google.com/app/apikey).

## התקנה והגדרה

1.  **הורד את הקוד:** שכפל (clone) או הורד את קבצי הפרויקט.

2.  **התקן ספריות:** פתח טרמינל (Command Prompt / PowerShell / Terminal) בתיקיית הפרויקט והרץ:
    ```bash
    pip install google-genai moviepy Pillow numpy arabic_reshaper python-bidi imageio imageio-ffmpeg PyYAML
    ```

3.  **התקן ImageMagick:** התקן את התוכנה לפי ההוראות באתר, וודא במהלך ההתקנה שסימנת את האפשרות **"Add application directory to your system path"** (או דומה לה). לאחר ההתקנה, הפעל מחדש את הטרמינל או את המחשב.

4.  **הגדר מפתח Gemini API:** הגדר את המפתח שקיבלת כ**משתנה סביבה** בשם `GEMINI_API_KEY`. יש להגדיר זאת בטרמינל שממנו תריץ את הסקריפט:
    *   **Windows (cmd):** `set GEMINI_API_KEY=YOUR_API_KEY`
    *   **Windows (PowerShell):** `$env:GEMINI_API_KEY="YOUR_API_KEY"`
    *   **Linux/macOS:** `export GEMINI_API_KEY="YOUR_API_KEY"`

    (החלף את `YOUR_API_KEY` במפתח האמיתי שלך).

5.  **הכן קבצי קלט:**
    *   **`data/songs/`**: מקם כאן את קבצי ה-MP3 של השירים.
    *   **`config/song_list.json`**: עדכן את רשימת השירים בקובץ זה. לכל שיר יש להגדיר:
        *   `"name"` (חובה): שם השיר. **חייב להיות זהה לשם קובץ ה-MP3 (ללא הסיומת .mp3)!**
        *   `"youtube_url"` (מומלץ): קישור YouTube לשיר (חיוני ליצירת תמלול אוטומטי).
        *   `"artist"` (אופציונלי): שם האמן/זמר.
        *   `"language"` (אופציונלי): שפת המקור. `"en"` לאנגלית (ברירת מחדל) או `"yi"` ליידיש.
        *   `"hebrew_name"` (אופציונלי): שם השיר בעברית, לשימוש בכותרת המשנה בפתיח.
        *   `"lyrics_file"` (אופציונלי): שם קובץ טקסט המכיל את מילות השיר, שצריך להיות ממוקם בתיקיית `data/lyrics/`.
    *   **`data/lyrics/` (אופציונלי):** מקם כאן קבצי טקסט (`.txt`) עם מילות השירים.
    *   **`assets/` (אופציונלי):** התאם אישית פונטים (`assets/fonts/`) ותמונות רקע (`assets/backgrounds/songs/`).

6.  **בדוק תצורה (למתקדמים):**
    *   **`config/video_config.json`:** ניתן לערוך קובץ זה כדי לשנות הגדרות וידאו, גדלי פונטים, צבעים ומיקומים.
    *   **`config/system_instructions.yaml`:** מכיל את ההנחיות ל-API של Gemini. יש לערוך בזהירות רבה.

## הרצת התוכנה

ישנן 3 דרכים להריץ את התוכנה, מהקלה ביותר למתקדמת ביותר.

### שיטה 1 (מומלץ): הממשק הגרפי (GUI)

הדרך הפשוטה והנוחה ביותר להשתמש בכלי.
1.  ודא שמשתנה הסביבה `GEMINI_API_KEY` מוגדר.
2.  הרץ את הפקודה הבאה בטרמינל:
    ```bash
    python gui.py
    ```
3.  ייפתח חלון גרפי שבו תוכל:
    *   לבחור שיר קיים מהרשימה ב-`song_list.json` (השדות יתמלאו אוטומטית).
    *   להזין פרטים של שיר חדש.
    *   לספק נתיבים לקבצים חיצוניים (MP3, מילים, כתוביות).
    *   לבחור הגדרות מתקדמות כמו שפת המקור או אילוץ יצירה מחדש.
    *   לחץ על **"צור וידאו"** כדי להתחיל את התהליך. הפלט יוצג בחלון בזמן אמת.

### שיטה 2: הממשק האינטראקטיבי בטרמינל (Runner)

דרך נוחה למשתמשי טרמינל, המדריכה אותך צעד אחר צעד.
1.  ודא שמשתנה הסביבה `GEMINI_API_KEY` מוגדר.
2.  הרץ את הפקודה:
    ```bash
    python runner.py
    ```
3.  יוצג תפריט פשוט בטרמינל. בחר אם ברצונך לעבד שיר קיים או להוסיף שיר חדש.
4.  הסקריפט ישאל אותך סדרת שאלות כדי לאסוף את כל המידע הדרוש (שם השיר, קישורים, קבצים וכו'), ולאחר מכן יפעיל את התהליך באופן אוטומטי.

### שיטה 3 (למתקדמים): הרצה ישירה של main.py

זוהי הרצה של מנוע התוכנה ישירות עם דגלים (flags) מהטרמינל. שימושי לאוטומציה או למשתמשים מנוסים.

*   **בחירת שיר ספציפי מהרשימה:**
    ```bash
    python main.py --select "שם השיר המדויק"
    ```
    (ניתן להשתמש גם במספר אינדקס או ב-YouTube ID כמזהה).

*   **הוספה ועיבוד של שיר חדש:**
    ```bash
    python main.py --add --name "שם השיר החדש" --url "קישור_יוטיוב" --artist "שם האמן"
    ```
    *   חובה לציין `--name` ו-`--url` (או קבצי כתוביות עם `--source-subtitles-path` ו-`--target-subtitles-path`).

*   **אפשרויות נוספות (ניתן לשלב עם הפקודות הנ"ל):**
    *   `--force-regenerate`: כופה יצירה מחדש של כתוביות מה-API (מתעלם מקבצי SRT קיימים).
    *   `--language <en|yi>`: קובע במפורש את שפת המקור (עוקף את ההגדרה ב-JSON).
    *   `--lyrics-file <PATH>`: שימוש בקובץ מילים ספציפי.
    *   `--source-mp3-path <PATH>`: העתקת קובץ MP3 חיצוני לתוך הפרויקט.

## פלט

*   **וידאו סופי (MP4):** נשמר בתיקיית `output/`, בשם `<שם_השיר>_subtitled.mp4`.
*   **קבצי כתוביות (SRT):** נשמרים בתיקיית `srt_files/`. קבצים אלו משמשים כ"זיכרון מטמון" (cache) כדי למנוע יצירה מחדש של כתוביות שכבר נוצרו, וחוסכים זמן ועלויות API בהרצות חוזרות.
*   **פריימים זמניים:** תיקיית `output/subtitle_frames/` נוצרת במהלך הריצה כדי לשמור פריימים לדוגמה של הכתוביות, ונמחקת אוטומטית בסיום מוצלח של התהליך.

## פתרון בעיות נפוצות

*   **`FileNotFoundError`:** בדוק נתיבים ב-`video_config.json`, ודא שקובצי MP3, פונטים ותמונות רקע קיימים בתיקיות הנכונות וששמותיהם תואמים להגדרות.
*   **שגיאת API Key / אימות:** ודא שמשתנה הסביבה `GEMINI_API_KEY` הוגדר נכון בטרמינל הנוכחי לפני הרצת הסקריפט.
*   **שגיאות ImageMagick / טקסט לא מופיע:** ודא ש-ImageMagick מותקן ונמצא ב-PATH של המערכת. הפעל מחדש את הטרמינל או את המחשב לאחר ההתקנה.
*   **שגיאות טעינת SRT:** ודא שקובצי SRT קיימים תקינים (בקידוד UTF-8). ניתן למחוק קבצים פגומים ולהשתמש בדגל `--force-regenerate` כדי ליצור אותם מחדש.
*   **תצוגת עברית הפוכה בטרמינל:** בעת שימוש ב-`runner.py`, ודא שהחבילה `python-bidi` מותקנת. במערכות Windows ישנות, ייתכן שתצוגת הצבעים והעברית לא תהיה מושלמת.
