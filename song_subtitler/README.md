# יוצר סרטוני כתוביות - מדריך למשתמש

## תיאור

כלי אוטומטי ליצירת סרטוני כתוביות לשירים. הכלי משלב קובץ אודיו (MP3), תמונת רקע, וכותרות, ומייצר כתוביות מסונכרנות בשפת המקור (אנגלית/יידיש) ובתרגום לעברית באמצעות Google Gemini API.

## דרישות

*   **Python 3.10+**
*   **Pip** (מנהל החבילות של Python)
*   **ImageMagick:** **חובה להתקין ולהוסיף ל-PATH של המערכת!** נדרש על ידי `moviepy` לעיבוד טקסט. [קישור להורדה](https://imagemagick.org/script/download.php).
*   **מפתח API של Google Gemini:** נדרש ליצירת הכתוביות. [ניתן להשיג מפתח כאן](https://aistudio.google.com/app/apikey).

## התקנה והגדרה

1.  **הורד את הקוד:** שכפל (clone) או הורד את קבצי הפרויקט לתיקייה במחשבך.

2.  **התקן ספריות:** פתח טרמינל (Command Prompt / PowerShell / Terminal) בתיקיית הפרויקט והרץ את הפקודה:
    ```bash
    pip install google-genai moviepy Pillow numpy arabic_reshaper python-bidi imageio imageio-ffmpeg PyYAML
    ```

3.  **התקן את ImageMagick:** התקן את התוכנה מהקישור למעלה. במהלך ההתקנה, ודא שסימנת את האפשרות **"Add application directory to your system path"** (או ניסוח דומה). לאחר ההתקנה, **הפעל מחדש את הטרמינל** או את המחשב.

4.  **הגדר מפתח API:** הגדר את המפתח שקיבלת כ**משתנה סביבה** בשם `GEMINI_API_KEY` בטרמינל שממנו תריץ את הסקריפט:
    *   **Windows (cmd):** `set GEMINI_API_KEY=YOUR_API_KEY`
    *   **Windows (PowerShell):** `$env:GEMINI_API_KEY="YOUR_API_KEY"`
    *   **Linux/macOS:** `export GEMINI_API_KEY="YOUR_API_KEY"`

    *(יש להחליף את `YOUR_API_KEY` במפתח האמיתי שלך)*.

## איך זה עובד? (תהליך הקלט)

התוכנה מנהלת את כל קבצי הקלט (שירים, מילים, כתוביות) בתיקיות הפרויקט (`data/`). אין צורך לערוך קבצי הגדרות (JSON) או למקם קבצים ידנית מראש.

בעת הוספת שיר חדש (דרך הממשק הגרפי או ה-Runner), תתבקשו לספק את הקבצים הנדרשים, והם יועתקו ויתארגנו במקומות הנכונים באופן אוטומטי.

#### שימוש ללא API (אופציונלי)

כדי להימנע משימוש ב-API של Gemini (ולחסוך בעלויות), ניתן לספק קבצי כתוביות מוכנים מראש. כאשר הסקריפט מזהה קבצים כאלה, הוא ישתמש בהם וידלג על שלבי התמלול והתרגום.

*   **איך זה עובד?** פשוט ספקו את נתיב הקובץ כשתתבקשו לכך בממשק הגרפי או ב-Runner.
*   **איזה קבצים?** קבצי `SRT` או `JSON` עם תזמונים.
*   **מה עוד?** ניתן לספק קובץ טקסט (`.txt`) עם מילות השיר (ללא תזמון) כדי לסייע ל-AI ליצור תמלול מדויק יותר.

## הרצת התוכנה

ישנן 3 דרכים להריץ את התוכנה, מהפשוטה למתקדמת.

### שיטה 1: הממשק הגרפי (GUI) - מומלץ

הדרך הקלה והנוחה ביותר. הרץ בטרמינל:
```bash
python gui.py
```
הממשק מאפשר לבחור שירים קיימים, להוסיף חדשים, לספק קבצים חיצוניים (כמו MP3 או כתוביות מוכנות) ולהתחיל את תהליך יצירת הסרטון בלחיצת כפתור.

### שיטה 2: הממשק האינטראקטיבי בטרמינל (Runner)

דרך נוחה למשתמשי טרמינל, המדריכה אותך צעד אחר צעד באמצעות שאלות. הרץ:
```bash
python runner.py
```

### שיטה 3: הרצה ישירה (CLI) - למתקדמים

הרצה של מנוע התוכנה (`main.py`) ישירות עם דגלים (flags). שימושי לאוטומציה. פירוט מלא של האפשרויות נמצא בסוף המדריך.

## פלט

*   **וידאו סופי (MP4):** נשמר בתיקיית `output/`, בשם `<שם_השיר>_subtitled.mp4`.
*   **קבצי כתוביות (SRT):** נוצרים ונשמרים בתיקיית `data/srt_files/`. קבצים אלו משמשים כ"זיכרון מטמון" (cache) כדי למנוע יצירה מחדש של כתוביות שכבר נוצרו וניתן גם להשתמש בהם לכל שימוש אחר.
*   **קבצים זמניים:** נוצרים במהלך הריצה ונמחקים אוטומטית בסיום מוצלח.

## אפשרויות הרצה מתקדמות (main.py CLI)

זוהי הרצה של מנוע התוכנה ישירות עם דגלים (flags) מהטרמינל.

#### **בחירת שיר או הוספה**
*   `--select <IDENTIFIER>` או `-s <IDENTIFIER>`: בוחר שיר קיים לעיבוד (לפי אינדקס, ID, או שם).
*   `--add`: מפעיל מצב הוספת שיר חדש. דורש דגלים נוספים (`-n`, `-u`).

#### **פרטי השיר (בעיקר עם `--add`)**
*   `--name <NAME>` או `-n <NAME>`: **[חובה עם `--add`]** שם השיר.
*   `--artist <ARTIST>` או `-ar <ARTIST>`: [אופציונלי] שם הזמר.
*   `--hebrew-name <H_NAME>` או `-hn <H_NAME>`: [אופציונלי] שם השיר בעברית.
*   `--url <URL>` או `-u <URL>`: **[חובה עם `--add` אלא אם סופקו כתוביות]** קישור YouTube לשיר.

#### **שימוש בקבצים חיצוניים**
*   `--target-subtitles-path <PATH>` או `-ts <PATH>`: **[חוסך API]** נתיב לקובץ כתוביות מתורגמות (SRT/JSON).
*   `--lyrics-file <PATH>` או `-lf <PATH>`: נתיב לקובץ טקסט עם מילות השיר (לסיוע ל-AI).

#### **בקרת תהליך**
*   `--force-regenerate` או `-f`: כופה יצירה מחדש של כתוביות מה-API, גם אם קיימות.
*   `--language <en|yi>` או `-l <en|yi>`: קובע במפורש את שפת המקור.
*   `--intro-subtitle <artist|hebrew>` או `-is <artist|hebrew>`: קובע מה יוצג בכותרת המשנה בפתיח (`artist` או `hebrew`).

## פתרון בעיות נפוצות

*   **`FileNotFoundError`:** בדוק נתיבים בקובץ `config/video_config.json`, ודא שקובצי הפונטים ותמונת הרקע קיימים בתיקיות הנכונות.
*   **שגיאת API Key / אימות:** ודא שמשתנה הסביבה `GEMINI_API_KEY` הוגדר נכון בטרמינל הנוכחי שממנו אתה מריץ את הסקריפט.
*   **שגיאות ImageMagick / טקסט לא מופיע בסרטון:** ודא ש-ImageMagick מותקן כראוי ונמצא ב-PATH של המערכת. הפעל מחדש את הטרמינל או את המחשב לאחר ההתקנה.
*   **שגיאות טעינת SRT:** ודא שקובצי SRT קיימים תקינים (בקידוד UTF-8). ניתן למחוק קבצים פגומים ולהשתמש בדגל `--force-regenerate` כדי ליצור אותם מחדש.
*   **תצוגת עברית הפוכה בטרמינל:** בעת שימוש ב-`runner.py`, ודא שהחבילה `python-bidi` מותקנת. במערכות Windows ישנות, ייתכן שתצוגת הצבעים והעברית לא תהיה מושלמת.
